# 승인 0건 발행이 막히는가 — 눈으로 읽은 것 (FINDINGS 80 · 커밋 f9962cb)

세 경우를 컴파일러에 그대로 넣고, 발행 라우트의 `COMPILE_ERROR_FAULT` 표가
그것을 무엇으로 옮기는지까지 이어서 찍었다.

- ①②는 **막혀야 하는데 예전에는 201 이었다.** 이유는 `.claude/rules/workflow.md`
  (제품이 넣는 고정 텍스트)가 항상 나가서 `files.length` 가 0 이 될 수 없었기 때문이다.
- ③의 출력이 그 함정을 그대로 보여 준다 — workflow.md 는 **근거 0개**로 나가 있고,
  Pack 이 「비지 않았다」고 말할 수 있게 하는 것은 **CLAUDE.md 의 근거 1개**뿐이다.
  그래서 가드가 세야 하는 값은 파일 수가 아니라 `source_item_ids` 다.
- ③의 마지막 줄이 P7 이다 — 사람이 답한 문장이 `src:manual:<질문 문장>` 으로 되짚어진다.

```

────────────────────────────────────────────────────────────────────────
① 씨앗 질문 10장에 답만 하고 승인은 안 했다 (항목 전부 draft)
────────────────────────────────────────────────────────────────────────
컴파일 막힘 — CompileError.code = EMPTY_SNAPSHOT
  message: Pack 에 항목에서 온 줄이 하나도 없다 (전부 제외됐거나 snapshot 이 비었다)

  → 화면이 받는 응답 (HTTP 400):
    {
      "error": {
        "code": "VALIDATION_FAILED",
        "message": "승인된 항목이 하나도 없습니다 — Context 에서 초안을 승인한 뒤에 발행하세요",
        "details": {
          "code": "EMPTY_SNAPSHOT"
        }
      }
    }

────────────────────────────────────────────────────────────────────────
② 문서도 항목도 하나도 없다 (빈 snapshot)
────────────────────────────────────────────────────────────────────────
컴파일 막힘 — CompileError.code = EMPTY_SNAPSHOT
  message: Pack 에 항목에서 온 줄이 하나도 없다 (전부 제외됐거나 snapshot 이 비었다)

  → 화면이 받는 응답 (HTTP 400):
    {
      "error": {
        "code": "VALIDATION_FAILED",
        "message": "승인된 항목이 하나도 없습니다 — Context 에서 초안을 승인한 뒤에 발행하세요",
        "details": {
          "code": "EMPTY_SNAPSHOT"
        }
      }
    }

────────────────────────────────────────────────────────────────────────
③ 그 한 장을 승인했다 (status 만 draft → active)
────────────────────────────────────────────────────────────────────────
컴파일 OK — 나온 Pack:
  .claude/rules/workflow.md        근거 0개
```
