✅ 된 것
  - 탐지 4종 전부 버튼마다 결과가 붙었다:
      「A가 맞음」→ B 항목 → 「폐기」 / 「B가 맞음」→ A 항목 → 「폐기」
      「둘 다 보류」·「무시」→ 항목은 그대로
  - 폐기가 일어나는 카드에만 마지막 줄이 붙는다 (⑪⑫ 질문 카드에는 없다).
  - ⑨ 결정된 카드가 「정했습니다 — 「코드가 맞음 (문서 갱신)」 · A 항목 → 「폐기」」로
    무엇이 없어졌는지를 말한다. ⑩ 무시됨은 「항목은 그대로」다.
  - 조사가 안 붙는다 — 화살표로 적었고 상태 이름(「폐기」)이 줄 끝이다.

🔴 읽다가 새로 보인 것 → FINDINGS 76 으로 적었다
  ④ 중복 카드가 「A로 합침」이라고 묻는데 결과 줄은 「B 항목 → 「폐기」」다.
  서버는 **합치지 않는다** — 진 쪽을 폐기할 뿐이다. 결과를 적기 전에는 안 보였다.

⚠ 이 파일이 재지 못한 것 (여전히 캡처가 있어야 한다)
  - 버튼 넷 밑에 캡션이 하나씩 붙어 카드가 더 길어졌다. 스무 장이 쌓였을 때
    스크롤이 어떤지는 못 잰다.
  - 캡션(`meta`)이 버튼 글씨보다 작아 보이는지 · 마지막 경고 줄의 `ink-warn` 이
    카드 안에서 너무 세지 않은지.
