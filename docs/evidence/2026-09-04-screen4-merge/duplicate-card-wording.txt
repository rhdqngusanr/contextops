 눈으로 읽고 판정한 것
=====================================================================

✅ 된 것
  - ④ 「A만 남김 | B 항목 → 「폐기」」 — 버튼과 결과가 **같은 말**을 한다.
    「A만 남김」이 참인 이유가 바로 옆 줄에 있다(B 가 폐기된다).
  - 탐지 4종 중 「합침」·「병합」류 낱말을 쓰는 버튼이 **하나도 없다.** 넷 다
    「진 쪽이 폐기된다」는 같은 일을 하고, 문구는 **어느 쪽이 이기는 이유**만 다르다
    (맞음 / 최신 / 만 남김 / 문서·코드).
  - 결과 줄과 마지막 경고 줄은 안 건드렸다 — 29바퀴가 만든 `choiceItemEffect()` 를
    그대로 읽는다. 문구만 바뀌었고 「무엇이 일어나나」를 적는 자리는 하나 그대로다.

⚠ 이 파일이 재지 못한 것
  - 「A만 남김」과 「B 항목 → 「폐기」」가 **같은 말을 두 번** 하는 것처럼 읽히는지.
    글자로는 짧아 보이지만 카드 안에서 두 줄이 붙으면 다르게 보일 수 있다 — 캡처가 있어야 한다.
  - DESIGN_BRIEF 가 그리려던 「같음, 용어: ___」·「다름」은 **여전히 없다** (FINDINGS 72①).
    지금 화면은 탐지 종류 공통 버튼 넷뿐이고, 중복 카드만의 문은 없다.
