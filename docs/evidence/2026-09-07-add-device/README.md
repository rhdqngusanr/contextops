## 판정

- ✅ 토큰만 썼다 — 임의 색·간격 0. 다크 고정
- ✅ **accent 는 화면당 하나** — [기기 추가] 뿐이고, 열린 뒤의 [토큰 발급]·[복사]·[닫기]는 전부 outline
- ✅ 상태를 색만으로 말하지 않는다 — 「한 번만 보인다」 경고가 ⚠ + 문장이다
- ✅ 발급된 값 옆에 **한 줄이 통째로** 있고 `--device-id` 까지 박혀 있다
- ✅ 게스트는 **누른 자리에서** 이유를 듣는다 (모달이 아니라 `role="status"`)
- 🔴 **고친 것** — 첫 캡처에서 발급된 카드에 [닫기] 가 **둘**이었다(머리의 토글 + 카드 자신).
