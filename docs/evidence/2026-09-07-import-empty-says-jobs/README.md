# 빈 상태가 세는 것을 말한다 — 진짜 브라우저에서 본 것 (FINDINGS 159 · 100바퀴 · `073308a`)

헤드리스 Chrome 을 CDP 로 몰아 **실제 `demo:db` + `next dev`(3111)** 위에서 찍었다 (1440×900).
들어간 길은 제품과 같다: `/demo` → 게스트 세션 → `/t/demo/p/paylab-api/import`.

| | 전 (98바퀴 · `../2026-09-07-demo-no-phantom-job/02-structure-panel.png`) | 후 (`01-structure-panel.png`) |
|---|---|---|
| 「구조화 진행」 칸의 문장 | `아직 올린 문서가 없습니다. 왼쪽에 문서를 붙여넣어 보세요.` | **`구조화 중인 문서가 없습니다. 왼쪽에 문서를 붙여넣고 [구조화하기] 를 눌러 보세요.`** |
| 그 말이 사실인가 | **아니다** — 데모 프로젝트에 문서가 2건 있다 | **그렇다** — 없는 것은 job 이다 |
| 빈 상태의 자리 이름 | `import.docs` | **`import.jobs`** (세는 것과 이름이 같다) |

같이 잰 것 (`shot.mjs` 의 콘솔 · 화면과 **같은 세션**으로 진짜 HTTP):

| 잰 것 | 값 |
|---|---|
| `/demo` 뒤에 선 자리 | `/t/demo/p/paylab-api/context` (게스트 세션이 붙었다) |
| 칸이 「아직 올린 문서가 없습니다」라고 하나 | **아니다** (`saysUploadedDocs: false`) |
| 칸이 「구조화 중인 문서가 없습니다」라고 하나 | **그렇다** (`saysStructuring: true`) |
| `GET …/jobs?feature=structure&limit=50` (`count.mjs`) | **0개** — 그래서 빈 상태가 선다 |
| 데모 프로젝트의 문서 | **2건** — 씨앗이 `POST /projects/{id}/documents` 를 201 로 두 번 부른다 (`demo:db` 로그) |

⚠ **문서는 `GET` 으로 못 센다** — 문서 라우트에 `GET` 이 없어서 `405` 다 (`count.mjs` 가 그렇게 답했다).
그래서 문서 건수는 **씨앗 서버가 낸 요청 로그**로 셌다. 「문서 목록」이 필요해지면 그건 새 라우트다 —
여기서 열지 않았다.

## 눈으로 본 것

`01-structure-panel.png` 에서 그 칸은 **문장 하나**이고 버튼이 없다 — 갈 곳이 같은 화면 왼쪽 칸이라
`noNext` 다 (`EMPTY_PLACES` 의 규칙). 문장이 가리키는 [구조화하기] 버튼이 실제로 그 왼쪽 카드 아래에
있다. accent 는 여전히 그 버튼 하나다.
